# woerterbuch
Einfaches Wörterbuch für Textverständnis in der 5. Klasse.

## Design Entscheidungen
- Reine Statische Seite für GitHub Pages, kein Backend, keine Datenbank
- Einfaches HTML + Vanilla JS mi Bootstrap 5, keine Frameworks, kein npm
- Keine CDNs, keine externen Fonts, alles lokal
- Das Wörterbuch ist in einer txt-Datei gespeichert, die beim Laden der Seite geparsed wird.
- Tablet first Design
